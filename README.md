# Queue System

A cross-platform Flutter application for managing student service queues in a school setting. Students can request services (tuition, documents), book time slots, and receive queue numbers. Cashiers can manage the queue, and admins can manage users, documents, and schedules.

---

## 📱 Features

- **Students:** Request services, book time slots, view tickets, track queue status
- **Cashiers:** Search students by name/number, manage queue, mark served/passed
- **Admins:** Manage users, documents, schedules, and appointments

---

## 🛠️ Tech Stack

- **Framework:** Flutter (Dart)
- **Backend:** Firebase (Firestore + Authentication)
- **Platforms:** Web (Chrome), Android, iOS
- **Architecture:** Cross-Platform / Serverless BaaS
